# Resultados de la evaluación final

- `comparacion_codigo.md`: tabla consolidada de las seis corridas, equivalencia funcional y criterio de medición. Es la referencia cuantitativa actual.
- `waveforms/`: dos VCD de C, siete vistas GTKWave y nueve capturas que sustentan las siete secciones de evidencia del informe (la etapa D ocupa tres capturas). `waveforms/comparativa_docente/` añade tres VCD y tres imágenes de A/B/C para la presentación, con interpretación y comandos de reproducción en su `README.md`.
- `medicion_docente_preliminar.md`: registro intermedio del programa docente. Para comparar ambos programas, usar `comparacion_codigo.md`.

La regresión que reproduce las cifras se ejecuta desde `EF/` con `./run_code_checks.ps1`. Las interpretaciones de las capturas están en `informe/Informe_Final_Proyecto2_BTB.pdf`.
